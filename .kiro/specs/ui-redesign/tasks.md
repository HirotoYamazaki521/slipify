# 実装計画 — ui-redesign

## 実行順序の概要

```
Task 1（基盤）→ Task 2 + Task 3(P) → Task 4(P) + Task 5(P) + Task 6(P) → Task 7（統合確認）
```

- **Task 1** はすべての土台。他タスクのクラス定数・ベーススタイルを提供する。
- **Task 3** は Task 1 完了後、Task 2 と並行実施可能（別ファイル群）。
- **Task 4・5・6** は Task 1 + 2 完了後、互いに並行実施可能（別ファイル）。
